## What this model is

L1은 Lunit과 Lunit Consortium이 만든 의료 도메인 특화 causal language model이다. `trillionlabs/Gravity-16B-A3B-Base`를 기반으로 하며, 임상 추론과 의사결정 지원을 주 용도로 설명한다.

- Architecture: GravityMoE, sparse mixture-of-experts with MLA
- Parameters: 16.24B total, 약 3B active per token
- Layers: 28
- Hidden size: 2,048
- Attention heads / KV heads: 16 / 16
- Experts: routed 64개 중 token당 top-8, shared 1개
- Context length: 32,768 tokens
- Vocabulary: 151,552
- Precision: bfloat16
- Tokenizer family: GLM-4.5
- Response behavior: 최종 답변 전 `<think>...</think>` 블록을 생성할 수 있는 thinking model

## Agent-facing operational notes

1. 이 저장소의 문서와 JSON은 모델을 **이해하기 위한 context**다. 모델 가중치를 Codex가 직접 읽거나 실행 가능하게 만드는 장치가 아니다.
2. 실제 추론에는 Hugging Face에서 별도로 모델을 받아 GPU 환경에서 Transformers, SGLang 또는 호환 serving stack으로 실행해야 한다.
3. 모델은 `trust_remote_code=True`를 요구한다. 프로덕션 사용 전 원격 Python 코드를 검토하고 revision을 고정한다.
4. 모델 카드의 예시는 reasoning overhead 때문에 `max_tokens` 또는 `max_new_tokens`를 2,048 이상으로 잡는다.
5. 의료 출력은 전문적 판단을 대체하지 않는다. 사실 오류, 누락, 오래된 정보 가능성을 전제로 검증한다.
6. 이 해커톤의 실제 대상인 `Lunit/L2-preview`와 L1은 서로 다른 모델이다. L1 문서를 L2의 retrieval/generation 계약으로 간주하지 않는다.
7. Evaluation 환경은 외부 네트워크가 차단되므로, 제출 container가 런타임에 이 Hugging Face 저장소를 내려받도록 설계하면 안 된다.

## Minimal inference references

Transformers:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "learning-unit/L1-16B-A3B"
tokenizer = AutoTokenizer.from_pretrained(model_id, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    model_id,
    device_map="auto",
    torch_dtype="auto",
    trust_remote_code=True,
)
```

SGLang is the model-card-recommended serving path. The current upstream instructions should be checked before installation because its custom GravityMoE support can change.
